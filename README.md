# Uganda Rainy-Season Access

Interactive map of travel time to hospitals, health centres, schools and markets in Uganda, month by month, and how much the rains lengthen it, down to the sub-county.

**Open the map:** https://gavacharles.github.io/uganda-rainy-season-access/

The page is a single self-contained file (`index.html`): it also works offline if downloaded and opened in a browser.

Data: OpenStreetMap roads (© OpenStreetMap contributors, ODbL); Ministry of Health public and not-for-profit facility list as geocoded by Maina et al. (2019); WorldPop 2020 population (CC BY 4.0); CHIRPS rainfall 2006–2025; HDX COD-AB administrative boundaries; Meta Relative Wealth Index. Motorised travel unless marked on foot. Ferries are not modelled.
